# Smart Warehouse & Inventory Management System

A web-based system for managing warehouse inventory, products, suppliers, stock, and user roles.

## Technologies Used

- Java
- Spring Boot
- MySQL
- JPA/Hibernate
- Spring Security
- JWT
- Maven

## Features

- Product management
- Inventory and stock management
- Supplier management
- User role management
- JWT authentication
- Role-based access control
- REST APIs
